一键关闭屏幕 · 使用说明

只关显示器，不睡眠、不锁屏、不影响任何程序运行 · 适用于本机（联想 82JW / Windows）

一句话总览：Windows 系统本身没有「关闭显示器」的快捷键；联想笔记本的 Fn 组合键机型各异。所以这里给你做了一个双击即关屏的小程序，另附一个全局热键 Ctrl+Alt+Q。

1. 先回答：本机关屏快捷键有没有？

方式结论
Windows 系统自带快捷键没有「关闭显示器」的全局快捷键。Win+L 只是锁屏，屏幕依然亮着。
笔记本 Fn 组合键联想机型不统一：ThinkPad 多为 Fn+F3；IdeaPad / 小新 / Legion 等常见在 Fn+F2 一带。你这台没有装联想的显示器切换热键工具，因此大概率无效——可以顺手试一下 Fn+F2、Fn+F3。
电源选项自动关屏你现在是：接通电源时「从不」关闭显示器，用电池时 10 分钟关闭。所以插电时屏幕永远不会自己黑，这个小程序正好补上这个空档。
本程序双击图标即关屏，另支持全局热键 Ctrl+Alt+Q。

3. 三种用法（推荐第 1 种）

用法一：双击图标关屏（最简单）

  • 双击 关闭屏幕.exe → 约 1 秒后屏幕熄灭，机器继续运行。
  • 桌面已生成快捷方式 关闭屏幕，并绑定全局热键 Ctrl+Alt+Q：任何时候按下这三个键就关屏，不用去找图标。
为什么延迟 1 秒？因为关屏瞬间如果你的鼠标还在动，屏幕会立刻被「唤醒」。留 1 秒让手指离开鼠标、键盘，关屏才稳。

用法二：常驻热键模式

  • 双击 关屏热键.exe（或 热键模式.bat）→ 出现一个小窗口，保持开着；
  • 之后按 Ctrl+Alt+Q 即关屏；
  • 不想要了就关掉那个窗口（或按 Ctrl+C）。

用法三：命令行（适合自动化 / 计划任务）

python screen_off.py                 # 1 秒后关屏
python screen_off.py --delay 5       # 5 秒后关屏
python screen_off.py --lock          # 先锁屏、再关屏（点亮后需输密码）
python screen_off.py --hotkey        # 热键模式（Ctrl+Alt+Q）
python screen_off.py --hotkey --key L  # 换成 Ctrl+Alt+L
python screen_off.py --self-test     # 只体检，不关屏

4. 怎么把屏幕重新点亮

按电源键，或者动一下鼠标、敲一下键盘，屏幕立刻亮起，程序不中断。

一个要提前知道的事：屏幕黑掉后，鼠标和键盘的任意动作也会唤醒它——这是 Windows 的固定行为，系统不提供「只能由电源键唤醒」的开关。

如果你担心误碰鼠标把屏幕点亮，用 --lock 参数（先锁屏再关屏）：亮屏后看到的是登录界面，需要密码才能进桌面。

另外建议顺手检查一下电源键的行为，避免按电源键时把机器送去睡眠：

  • 控制面板 → 电源选项 → 选择电源按钮的功能 → 「按电源按钮时」建议改成 不采取任何操作（或「关闭显示器」）；
  • 这样按电源键只是唤醒屏幕，不会改变机器的运行状态。

5. 原理：为什么它不影响运行

程序调用的是 Windows 自带的系统命令 SC_MONITORPOWER（显示器省电指令），也就是电源选项里「X 分钟后关闭显示器」用的同一套机制：

  • 只让 显示器进入省电黑屏；
  • CPU、内存、硬盘、网络、下载、后台程序 全部照常运行；
  • 与「睡眠 / 休眠」完全不同——后者会暂停程序并断网。

程序的做法分两步兜底：先逐个通知所有可见窗口，再额外广播一次，因此对全屏播放器、旧软件也能生效。

6. 常见问题排查

现象原因与解决
双击后屏幕黑了一下又亮关屏瞬间鼠标/键盘被碰到了。把延迟调大：右键桌面快捷方式 → 属性 → 在「目标」末尾加 --delay 3。
双击后完全没反应先用 python screen_off.py --self-test 体检；若提示无法访问窗口站，说明是在后台服务/计划任务的非交互会话里运行，改成以当前用户身份、勾选「只在用户登录时运行」。
热键 Ctrl+Alt+Q 无效被其他软件占用了。换字母：python screen_off.py --hotkey --key L；桌面快捷方式的快捷键也可在「属性 → 快捷键」里改。
杀毒软件报陌生程序PyInstaller 打包的 exe 常被误报。可改用 关闭屏幕-静默.vbs（直接跑 Python 源码）或把文件加入白名单。
想关掉键盘/鼠标的唤醒能力设备管理器 → 对应设备 → 电源管理 → 取消「允许此设备唤醒计算机」。⚠ 注意：取消后键盘鼠标可能连唤醒都做不了，笔记本上请保留电源键唤醒，改前先确认能按电源键亮屏。

7. 附带的其他小工具（可选）

  • 把显示器超时改短让屏幕自己黑：powercfg /change monitor-timeout-ac 5（插电 5 分钟无操作自动关屏）。
  • 恢复你现在的设置：powercfg /change monitor-timeout-ac 0（0 = 从不关闭）。
  • 按需点亮屏幕（程序化开屏）：python screen_off.py --on。
